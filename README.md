# Developer Dashboard

A modern developer productivity dashboard built with Next.js 15, TypeScript, Tailwind CSS, Zustand, and Recharts.

## Overview

Developer Dashboard helps developers organize and track:

- Projects
- Job Applications
- Skill Progress
- Learning Activity

The application focuses on clean architecture, reusable UI components, accessibility, responsive design, and performance optimization.

## Features

### Dashboard
- Project statistics
- Application tracking
- Learning streak overview
- Recent activity feed
- Quick actions
- Search functionality

### Projects
- Create projects
- Edit projects
- Delete projects
- Status filtering
- Search projects
- Persistent local storage

### Applications
- Track job applications
- Update application status
- Filter applications
- Persistent local storage

### Skills
- Skill progress tracking
- Data visualization using Recharts
- Responsive charts

### UX & Accessibility
- Dark theme
- Responsive mobile navigation
- Keyboard navigation
- Accessible modals
- Focus states
- ARIA support

## Tech Stack

- Next.js 15
- TypeScript
- Tailwind CSS
- Zustand
- React Hook Form
- Zod
- Framer Motion
- Recharts
- Lucide React

## Performance Optimizations

- Zustand persistence
- Memoized components
- Dynamic imports
- Responsive chart optimization
- Production build optimization
